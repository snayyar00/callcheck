# Noise sources for synth/harden.py

No external noise corpus is used. All background noise is synthesized at run time, so there is no third-party licence to track.

| Type | How it is made |
|---|---|
| traffic | Brown noise (low-passed 400 Hz) + pink hiss + Gaussian "passing car" swells |
| tv | Babble: 6 snippets of speech taken from the other calls in the source set (half time-reversed), plus a faint tone bed, with slow amplitude wobble |
| fan | Pink noise + 100-130 Hz hum with 5 harmonics |
| car | Low-passed brown rumble + 40-70 Hz engine harmonics + low-passed pink wind |

Babble speech comes from macOS `say` voices generated by `synth/generate.py` (no real people). This is synthetic noise, so it is
spectrally simpler than recorded street or cafe noise; treat results as optimistic. For harder real noise, candidates (not used here):
ESC-50 (github.com/karolpiczak/ESC-50, CC BY-NC 3.0 for the clips, attribution required, non-commercial) and
MUSAN (openslr.org/17, CC BY 4.0 for the noise and music parts).
